Sistema web desenvolvido para simular o cadastro de atletas, permitindo registrar informações pessoais e médicas de forma prática e organizada.

O projeto possui uma interface intuitiva onde o usuário informa seu nome para iniciar a sessão, realiza o cadastro dos atletas e pode visualizar todos os registros em uma tabela.

## 🌐 Acesse o Projeto

🔗 **Demo Online:** https://cadastro-de-atletas-web.vercel.app/

---

## 🚀 Funcionalidades

- ✅ Tela inicial para identificação do usuário.
- ✅ Cadastro completo de atletas.
- ✅ Registro de dados pessoais.
- ✅ Registro de dados médicos.
- ✅ Visualização dos atletas cadastrados.
- ✅ Exclusão de atletas da lista.
- ✅ Interface simples e responsiva.


Abra o arquivo `index.html` no navegador ou utilize a extensão **Live Server** do VS Code.

---

## 🔄 Fluxo da Aplicação

1. O usuário informa seu nome na tela inicial.
2. É redirecionado para o formulário.
3. Preenche os dados do atleta.
4. As informações são armazenadas durante a execução da aplicação.
5. Os atletas cadastrados podem ser consultados na tela de listagem.
6. Caso necessário, um registro pode ser removido.
